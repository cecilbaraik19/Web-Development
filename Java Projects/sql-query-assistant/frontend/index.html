Prashna

Ask your database a question in plain English.

Type "top 5 students from Ranchi by CGPA". Prashna works out which tables, columns and values you mean, writes the SQL, runs it, prints the answer and explains every step – so you learn SQL while you use it.

  • Offline engine written in plain Java: no internet needed
  • Read-only: only SELECT can run, nothing can be changed or deleted
  • Learns when you correct it
